## 월간 판정 질문
AI 제품은 어느 영역에서 시범을 넘어 실제 운영 단계에 들어섰는가?

## 주간 스캔 범위
AI Assistant·Coding Agent·Autonomous Agent·AI 개발 플랫폼·Agent Framework·Physical AI·Robotics·자율주행 등의 신규 서비스 출시와 기능 확대, 기업 및 산업별 AI 도입·상용화 사례, 서비스 이용량·성과, 실제 운영 결과와 실패 사례

## 한 줄 답 형식: 상용화 단계
영역마다 발표 → 베타(제한 이용) → 정식 출시 → 대규모 운영(이용량·성과·매출이 공개됨) 중 현재 위치를 글로벌과 한국으로 나눠 판정한다. 출시 발표만으로는 '정식 출시'까지만 인정한다.

영역: AI Assistant · Coding Agent · 업무형 Autonomous Agent · 로보택시 · 휴머노이드·로봇 · 기업 내 Agent 도입 · (Agent 개발 플랫폼·표준)
