# AI Future Customer Lab

고객과 시장이 AI로 어떻게 바뀌는지를 추적한다. 기업의 대응·실행 사례는 "AI Sales & Marketing", 산업·기술 동향은 "AI Industry Trend"에서 다룬다.

## 고정 질문 v1.0 (2026-10-09 확정)

| 번호 | 질문 | 한 줄 답 형태 | 상태 |
|---|---|---|---|
| C1 | 소비자는 탐색→답변→추천→결정→위임 중 어느 단계까지 AI에 맡기고 있으며, 검색엔진·브랜드 사이트의 역할은 얼마나 줄었는가? | 5단계별 실험·얼리어답터·확산·주류 판정 | R1 완료 |
| C2 | 고객 여정(발견·상담·판매·관계) 중 어느 접점이 AI Agent로 넘어가고 있으며, 그 접점의 주도권은 브랜드·플랫폼·고객 Agent 중 누구에게 있는가? | 접점별 주도권 지도 | R1 완료 |
| C3 | 소비자가 구매 판단에 쓰는 정보의 원천은 사람이 만든 것에서 AI가 만든 것으로 어디까지 옮겨갔고, 소비자는 그것을 믿는가? | 정보 원천 비중 + 신뢰 방향 | R1 완료 |
| C4 | 집 안에서 AI가 스스로 판단·실행하는 범위는 어디까지 왔으며, 고객은 어느 수준의 자율을 받아들이는가? | 자율 수준 L0~L4 위치 | R1 완료 |
| C5 | 어떤 가구 변화와 생활 사건이 새로운 수요를 만들고 있는가? | 수요를 만드는 변화 순위 | R1 완료 |

질문과 추적 지표는 분기에 한 번만 바꾼다. 바꾸면 버전을 올리고 이전 기록은 그대로 둔다.

- **R1 (2026-10-09, 기준 회차):** 기록 40건 (지표 15 · 사건 11 · 해석 6 · 전망 8 — 메인 질문 낙관·비관 시나리오 2 + 세부 판정 전망 6)

  - 아티클: [`c1/article_r1.html`](c1/article_r1.html)

## 파일

| 파일 | 내용 |
|---|---|
| `c1/request_r1.md` | R1 딥리서치 요청서 (질문, 추적 지표, 출처 기준) |
| `c1/records.jsonl` | 4유형 기록 원본 DB |
| `c1/build_records.py` | 기록 생성과 규칙 검증 (근거 연결, 전망의 시점·확인 방법, ID 무결성) |

| `c1/article_r1.html` | R1 기준 아티클 |
| `c2/…` ~ `c5/…` | C2~C5 같은 구성 |
| `../lib/article.css` | 아티클 공통 스타일 (저장소 루트) |

cd customer-lab/c1
